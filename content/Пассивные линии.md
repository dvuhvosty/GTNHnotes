
Данный документ содержит список пассивных линий и требования к ним:

В топливную сеть чиплета подаётся HOG при помощи dual - интерфейса - заглушка для legacy-линий

Пассивная линия принимает продукт любым доступным способом с учётом специфики данной линии:
- Ручной ввод
- Активный импорт из ME через import bus (сильнее всего влияет на TPS)
- Подключено через Storage bus мейннета как единственное хранилище данного продукта 
- Сабнет видит своё сырьё в мейннете через storage bus сабнета 
- Me interface

**Вывод пассивной линии должен обрабатываться одним единственным способом** (Исключение-фризер) - Внутреннее хранилище пассивной линии, подключенное через storage bus мейннета (bi-directional or export only). Такой способ подключения обеспечивает:
- Остановку пассивной линии при достижении лимита внутреннего хранилища
- Исключение сценария забития мейннета продуктами пассивной линии

#### Хлор - электролиз содалита
Электролиз содалита. 
Рецепт 3,3 сек: 11 sodalite dust -> 1000L хлора + 3 sodium dust + 3 silicon dust + 3 alumina dust.

| Параметр | Значение                                        |
| -------- | ----------------------------------------------- |
| Ввод     | Импорт из мейннета ME Interface - sodalite dust |
| Вывод    | Хлор - по стандарту; пыли - напрямую в мейннет  |
| Питание  | 1440 EU/t (≈0,7A EV)                            |
| Машины   | 1 x электролизёр, EV                            |

| Продукт      | Темп производства | Внутренний буфер             |
| ------------ | ----------------- | ---------------------------- |
| Хлор         | ≈303 L/sec        | 16ML супертэнк (export only) |
| Sodium dust  | ≈0,91/sec         | -                            |
| Silicon dust | ≈0,91/sec         | -                            |
| Alumina dust | ≈0,91/sec         | -                            |
**Особенности:** интерфейс тянет содалит из ME, пока тот не кончится, рядом сундук для ручного ввода KCl и NaCl на электролиз
**Проблемы:** -
