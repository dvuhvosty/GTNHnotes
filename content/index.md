## Коммуникационная сеть

Коммуникационная сеть соединяет чиплеты между собой и представляет собой подземные кабели, проложенные по единой логике.

> [!important] Правила прокладки
> - При прокладке кабелей следует придерживаться таблицы «Нормы прокладывания кабелей».
> - Дополнительные коммуникации **не допускаются**.
> - Допускается использование других уровней в целях разводки и обхода других кабелей.

> [!caution] Fluid P2P
> Не рекомендуется, но допускается использование fluid p2p тоннелей для транспортировки жидкостей, в том числе топлива.

### Нормы прокладывания кабелей

| Y-level | Назначение                |
| :-----: | ------------------------- |
| 7       | Кабель текущего тира      |
| 6       | Пол из каменных слэбов    |
| 5       | Высоковольтный кабель     |
| 4       | Резерв                    |
| 3       | Резерв                    |
| 2       | AE Main net (опционально) |
| 1       | AE P2P subnet             |
| 0       | Бэдрок                    |

> [!warning] Запрещено
> Использование между чиплетами дополнительных коммуникационных сетей, не предусмотренных таблицей выше. Octo-EBF сейчас в нарушении стандарта

## Архитектура чиплета
